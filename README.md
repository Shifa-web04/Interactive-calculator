# Nexora Calc — Interactive Calculator

A modern, responsive calculator developed using HTML, CSS and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication and division
- Decimal calculations
- Percentage functionality
- Clear and delete operations
- Keyboard support
- Calculation history
- Responsive user interface
- Error handling for invalid calculations

## Technologies Used

- HTML5
- CSS3
- JavaScript
